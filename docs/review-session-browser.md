# 会话浏览器与 transfer 的整体 review

日期：2026-11-12。范围包含 CLI/键盘状态机、查询与分页、格式适配器、转移写入、进程/终端清理、索引和缓存用途。合并保留了远程 `fd70eb4` 的 AGY 1.5.6 原生夹具、解码和恢复证据；未新增 README。

## review 修复

1. **AGY 思考/工具内容混入移交。** AGY 的展示正文包含思考、工具调用及最终回复。转移改为从已保存的原始 Protobuf 按需取可见回复路径，保留完整展示与搜索能力，却不把思考/工具当成助手正文复制。没有增加 decoded-reply 缓存或改变夹具哈希；回归覆盖真实 1.5.6 夹具与原生 Pi loader。
2. **不必要的整段文本复制。** 活动分支先验证 ID/父链，再移动选中消息，避免复制完整历史后再截尾；循环检测使用按节点索引的布尔表。线性格式不保留无用的父链/空事件节点。`--last` 仍验证完整分支，所以不宣称内存只与 N 成正比。
3. **输出缓存与碎片 I/O。** 三个文件目标通过小型 BufWriter 逐记录写出；OpenCode 的导入 payload 也逐消息写入私有临时文件，不再在 RAM 中额外构造完整消息数组/JSON 副本。原生字段 `messageID/sessionID` 明确标注，避免通用 camelCase 错写成 `messageId/sessionId`；回归验证字段和真实导入。
4. **成功/失败边界。** OpenCode 既检查退出码，也核对导入 ID 的成功确认，不能把“退出 0 但打印失败”当成成功。导入后新会话未出现在索引时明确警告。文件已发布后目录同步失败返回已创建会话的身份和警告，避免用户误以为没创建而重复写入。
5. **子进程与临时数据。** 原生导入关闭 stdin，限制 30 秒和 4 MiB 日志；在独立进程组中运行，超时/错误清理并 wait 子进程。测试包括超时回收，以及退出 0 也不能绕过日志上限。临时 payload/log 为私有临时文件，退出作用域释放；错误不回显完整原生输出。
6. **键盘与预览边界。** 连续输入合并后再查询，减少每个缓冲字符重复查库；修复 64 个事件批处理边界可能吞掉下一个字符的问题。回归包含长查询、中文、清空/取消、搜索中的回车不启动会话、预览取消不写入。标题按显示宽度流式裁剪，对过长零宽/控制字符序列设预览边界，不先复制完整长标题。
7. **只读来源路径保护。** 修复多层缺失目录上方的符号链接绕过索引/来源路径重叠检查；解析最近已有祖先，拒绝无法解析的悬空链接。测试确认不会在原始来源下创建索引或中间目录。

## 缓存取舍

- **保留 SQLite 派生索引。** 它提供跨 Agent 查询、FTS 和原始来源消失后的缓存查看；删除它会破坏现有功能，不因“缓存”一词盲目删除。
- **不新增整库/历史搜索结果缓存。** 选择器只保留当前数据页（默认 50 条、可显式调大）、6 个分类计数和当前查询，操作后直接查询 SQLite。输入批处理优化查询次数，不存多份旧结果。
- **保留 bounded SQLite page/statement cache。** 索引 page cache 目标约 4 MiB，来源副本约 2 MiB；插入语句缓存避免大量重复 prepare。它们随连接释放，不是后台服务。
- **保留单次同步的 AGY 汇总快照复用。** 一次 Adapter 生命周期内按指纹失效，避免每个会话都复制同一汇总 DB；退出后释放，不跨任务长期驻留。DB+WAL 私有快照用于只读一致性，也不是待永久保留的额外索引。
- **不保留第二份 AGY 回复缓存或完整导入 JSON。** 可见正文从原始数据按需提取，OpenCode payload 流式生成。
- **承认磁盘冗余。** raw、规范化正文、documents/FTS 分别服务于原文保真、逐条展示、检索；当前索引可能明显大于源文件。未在此次功能修改中冒然迁移 schema/压缩格式，避免破坏离线历史或读写一致性。转移生成的新原生会话是用户明确创建的数据副本，不自动作为“缓存”清除。

## 性能抽查

Linux x86_64 / Rust 1.85.0，单次本地合成负载、热缓存为主、非独占环境。源数据约 47.9 MiB，1,001 会话 / 120,000 消息，其中一个会话包含 20,000 条长消息。RSS 从 `/proc` 在 exec 后每 2 ms 采样，只计 AgentHub，不含原生客户端。以下是 review 构建的一次测量，不是平台性能承诺。

| 操作 | 时间 | AgentHub 峰值 RSS |
| --- | ---: | ---: |
| 首次同步 | 5.94 s | 9.98 MiB |
| 无变化同步 | 15.97 ms | 5.35 MiB |
| 静态列表 50 条 | 7.13 ms | 5.04 MiB |
| 大会话完整 transfer 预览 | 155.10 ms | 33.93 MiB |
| 大会话最后 10 条预览（仍验完整父链） | 172.35 ms | 33.19 MiB |
| 最后 1,000 条写入新 Codex 会话及索引 | 216.03 ms | 33.18 MiB |
| 交互搜索，高频 renderer | 112.73 ms | 未单独计量 |
| 交互搜索，较低频标记 | 25.41 ms | 未单独计量 |
| 交互搜索，两字中文 | 140.93 ms | 未单独计量 |

本次索引约 216.3 MiB（含测试中新增的 1,000 条目标消息副本），不能宣称磁盘占用与源文件相同。没有压测真实生产大库、并发 writer 或所有上游格式。

复现（手工基准，不放进常规 CI；数据目录自动清理）：

```sh
cargo build --locked --release --workspace
python3 scripts/benchmark_sessions.py --binary target/release/ah --output /tmp/ah-benchmark.json
```
